## The AI provider seam

User decision: AI stand-ins run the user's local `claude` or `codex` command-line tools; no API keys. The seam is in three places:

- Domain: `MaxSettings.provider: AIProviderChoice` (`off`, `auto`, `claude`, `codex`), `Session.detectedAI` (what launch found), `Session.pendingAI` (requests in flight), `AITask` (`renameTab`, `tidyToday`, `ask`), `AIOutcome` (`text`, `unavailable`, `failed`). `Work.requestAI(task)` emits `Effect.ai(id, task, choice:)`; `SystemEvent.aiResult(id, outcome)` applies the answer to the item the task names (`Rules/Assist.swift`). The one real caller today: pinning a tab with "renamed pinned tabs" on asks for a tidy title and the answer becomes the tab's `customTitle`.
- App: `BrkApp/AIProvider.swift`. `AIProviderSeam.detect()` looks for `claude` and `codex` on PATH and in the usual Homebrew and npm bins (a GUI app's PATH is short); `Lifecycle` dispatches `.aiProvidersDetected` at launch; the Max pane shows what was found and what `.auto` resolves to. `CLIProvider.run(prompt)` runs `claude -p <prompt> --output-format text` or `codex exec --skip-git-repo-check <prompt>` with stdin closed, collects stdout, bounded by a timeout. `AIPrompt.text(for:)` is the one place prompts are worded.
- Later wave: Tidy Tabs (the JSON plan contract), Ask Arc, ChatGPT in the command bar (`.later(.aiCommandBar)` row), 5-second previews; each adds an `AITask` case and a reducer arm.

On this Mac both tools are installed (`~/.local/bin/claude`, `~/.local/bin/codex`), so `.auto` resolves to `claude`.

## The export seam

User decision: share-by-link becomes file export. `AppCommand.export(ExportSubject)` (a space, the focused tab, chosen items) is the "Share…" row; the reducer builds an `ExportDocument` (title plus a tree of links and folders) from state and emits `Effect.export(document)`. `ExportCodec` (in `Codec.swift`, with the other file format) encodes it as JSON (our shape, sorted keys) or a Netscape bookmark HTML file every browser imports. `BrkApp/ShareExport.swift` shows the save panel (JSON or HTML by the chosen extension) and writes the bytes. Easel export joins when Easels do.

## Open questions

The table keeps both; `KeyBindings` reports a conflict and routes the chord to no one until the user resolves it in the Shortcuts pane (where Arc shows "Remove Conflicting Shortcut"). - Send to Dia: dropped from the table (a Browser Company product link). Confirm.

- Peek geometry (inset 40, radius 12, hint strip 28) and the Library strip height (44) are guesses; Arc's values were not recovered. F3 and F5 should measure them in the real Arc once the login wall is passed.
