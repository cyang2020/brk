# 对话只放在右边

## 背景

2026-11-09，用户看到侧边栏 Today 里有一行带对话图标的 "Greeting"，问："为什么会有对话变成左边的一个tab呢？理论上右边的conversation栏就是承载对话的呀？？还是说 每个tab都能对话？？"

当时一段对话会出现在六个地方：
- 侧边栏里的一行 tab。这是第 3 步"对话是 tab"加的：第一句话发出去时，Today 顶上就多一行。
- 中间的网页卡片。点侧边栏那一行，或点面板标题栏的"在 tab 里打开"，对话会在这里整页打开。
- 右边面板的对话页。
- 右边面板的对话列表，第 7 步加的。
- Library 的"AI 对话"页。
- 命令栏的搜索结果。

前两处和面板列表做的是同一件事，而且规则对不上：
- 侧边栏里点 × 是归档，列表里也能归档。
- 侧边栏里能 pin、能放文件夹，列表里不能。
- 点左边那一行，对话在中间打开；点右边那一行，对话在右边打开。

我先提议对话默认不进侧边栏，只有点"在 tab 里打开"时才出现一行。用户说："这样的就不是很合理吧。。。很乱啊 你觉得应该如何设计呢 你想想"。那个方案里对话有时在左边有时不在，点 × 也不算归档，特例太多。

我接着提了"左边只放网页，右边只放对话"。用户问："是不是左边的就没必要有ai对话呢。。。这样保证对话全都在右边"，又提了另一种做法："或者和arc左下角的那个bin一样 做一个小弹窗？hover的时候可以高亮每个被某个对话refer的tab？"。我建议不另做弹窗列表，把悬停高亮放进右边的列表。用户又问："右边现在没有一个地方放这个icon，你觉得应该怎么弄呢？还有哪里可以toggle这个 界面"。我提了下面"开关和入口"里的做法，用户回复："可以 就这么做"。

设计稿在 `docs/design/ai-right-panel-mockup.html`，四张图依次是：现在和改后的对比、鼠标停在对话上时左边亮起的 tab、标题行上的开关、拖 tab 到窗口右边。稿子里的颜色是示意，实现时用 Space 主题的实际取值。

## 左边只放网页，右边只放对话

规则只有一条：侧边栏里只有网页，包括用户点"存成 tab"存下来的 AI 页面；所有对话都在右边面板里。

这样分的理由：
- 网页和对话的用法不同。网页是看的结果，AI 做出来的"商品价格监控"也算网页，用户会反复打开、pin 住。对话是做事的过程，做完就往下沉，要用的时候再搜出来。
- 用户要长期留着的，是对话做出来的页面，不是对话本身。页面本来就是 tab，能 pin、能放文件夹，所以对话不需要这两样。
- 第 3 步把对话做成 tab，理由是"现在的对话关掉面板就没了"，而浏览器里能存下来、能找回来的东西就是 tab。那时面板还没有列表。现在面板列表、命令栏全文搜索、Library 的"AI 对话"页都能把对话找回来，侧边栏那一行只剩下重复。
- 反过来做，对话只放侧边栏、面板不要列表，也不行。侧边栏里点一行本来是换中间的网页，对话那一行却要在右边打开，又多一条特例；而且看网页的时候就看不到对话列表。
- 用户提的左下角小弹窗，如果做成另一个对话列表，就和面板列表做同一件事，又成了两处。而且在左边弹窗里点一段对话，它在右边打开，眼睛要从左跳到右。所以不另做列表。弹窗想法里的悬停高亮留下来，放进右边的列表：鼠标停在一段对话上，左边亮出它用过的 tab。

两边之间的来往只有两个方向：
- **网页进对话。** 把 tab 拖进面板、在输入框里 @、在 tab 上右键选 Ask AI、把 tab 拖到窗口右边。tab 交进来是给 AI 当材料，tab 自己还留在左边。
- **页面出对话。** 对话里做出的页面点"存成 tab"，放到左边。存下来的页面上有按钮，能回到做出它的那段对话。

## 对话不再占 tab

- 发出第一句话时，侧边栏不再多一行。对话照样存下来，出现在这个 Space 的面板列表里。
- 去掉所有"在 tab 里打开"：面板标题栏的、列表右键菜单里的、Library"AI 对话"页上的按钮。面板标题栏剩下新对话、列表图标、关闭。对话单独占一个 tab 时的那套样子不再用。
- 想把对话看宽一点，就拖宽面板。鼠标放在网页卡片和面板之间的空隙上，光标变成左右拖动的样子，按住往左拖。面板原来最宽 360 点，改成最宽到窗口宽度的一半；网页卡片至少留 400 点、面板最窄 280 点这两条不变。拖出来的宽度照侧边栏宽度的方式记住，重启以后还在。面板变宽以后，回答里的页面按新宽度排，之后告诉 agent 的页面宽度也用新宽度。
- 对话自己记住它属于哪个 Space。原来是看对话那一行 tab 在哪个 Space，那一行没有了，就记在对话里：在哪个 Space 开始的就属于哪个 Space，移过以后属于新的 Space。
- Space 被删掉时，它的对话不删，移到同一个 profile 里排在最前面的 Space。删 Space 的确认框里多写一句，比如"3 段 AI 对话会移到 购物"。没有对话时确认框和原来一样。

## 列表里只留删除

侧边栏那一行没了以后，pin、放进文件夹、点 × 归档、Today 的自动归档，这些对对话都不再有。列表里也不再有归档，原因有两个：一是对话按"等你处理""进行中""今天""昨天""更早"分组，旧的自然沉到下面，要用的时候搜得到；二是只留"彻底删除"一个动作，就不会有两处归档对不上。

- 右键菜单剩下：重命名、移到别的 Space、彻底删除…。
- 把列表里的一行拖到侧边栏底部的 Space 圆点上，对话就移到那个 Space，和把 tab 拖到 Space 圆点上一样。
- Library 的"AI 对话"页：去掉"在 tab 里打开"按钮；筛选里的状态不再有"已归档"。

**已有的对话行。** 更新后第一次启动时，侧边栏里所有对话行都拿掉，包括 pin 住的和在文件夹里的；归档里的对话记录也拿掉。对话本身都留着，归到那一行原来所在的 Space 的列表里。归档里的对话归到归档前所在的 Space，那个 Space 已经没有了，就归到同一个 profile 里排在最前面的 Space。文件夹拿掉对话行后空了，照 Arc 的规矩留着空文件夹。AI 页面那一行不动。

## 悬停高亮

鼠标停在面板列表的一行上，左边侧边栏里这段对话用过、现在还开着的 tab 会亮起来：用这个 Space 的主色描一圈边，底色淡淡加一层主色。鼠标移开就恢复。

"用过"的 tab 有两种：
- 用户交进来的：拖进来、@、Ask AI、拖到窗口右边。
- agent 用 Brk 的 tab 工具读过、打开过的。

按 tab 算，不按网址算：tab 后来换了网页也算。

亮在哪里：
- tab 是侧边栏里的一行（pinned 或 Today）：亮那一行。
- tab 在收起来的文件夹里：亮文件夹那一行。
- tab 在 Favorites 里：亮那个图标格子。
- tab 在分屏里：亮分屏那一行。
- tab 在别的 Space、已经关掉或归档：不亮。

鼠标停着时，这一行的第二行换成"用了 N 个 tab"。用过的不全在这里亮着时，写成"用了 N 个 tab，亮着 K 个"。

对话页里输入框上方的 tab 小标签也一样：鼠标停在一个小标签上，左边对应的那个 tab 亮。

侧边栏隐藏时不亮。亮的 tab 在侧边栏里滚出了可见范围时，侧边栏不跟着滚。

## 开关和入口

面板关着时，右边只有网页，没有地方放按钮。真要放只有两种办法，都不好：
- 浮在网页上，会挡住网站自己放在角上的头像、菜单、客服聊天按钮。
- 在右边留一条常驻的窄边，每个网页都会变窄。

Arc 把网页以外的按钮都放在侧边栏，右边整块留给网页，Brk 一直照这个做。所以开关放在左边。

**侧边栏最上面那一行（红绿灯那一行）的最右边，加一个对话按钮。**
- 这一行最左边已经有开关侧边栏的按钮，面板的开关放在同一行最右边，一个管左边，一个管右边。
- 不放在底部 Library 旁边：底部那一排放的是 Space 圆点，Space 一多本来就挤；Library 管的是归档和下载，跟对话放在一起意思也接不上。
- 图标用对话气泡，和命令栏"AI 对话"那一项、面板标题栏的列表图标是同一个。
- 点一下，面板打开，回到这个 Space 上次停的那一页；还没有对话时停在列表页。再点一下，面板关上。面板开着时，按钮底色和鼠标停在上面时一样，表示开着。
- 这个 profile 里有对话"等你处理"时，按钮右上角显示数字，和面板列表图标上的数字是同一个数，面板关着也能看到。
- 鼠标停上去显示"AI 对话 ⌥⌘A"，语言按列表文字的规则，英文时是"AI Conversations ⌥⌘A"。
- 侧边栏拉窄时，这一行现在会把刷新键收进"…"菜单。这个按钮排在刷新键后面收：刷新先收进去，位置还不够时它也收进去。收进去以后，"…"菜单里那一项后面写数字。
- 打开了"显示工具栏"时，前进后退和地址栏挪到网页上方的工具栏，这个按钮也挪过去，放在工具栏最右边。
- 只在这个窗口能用 AI 时显示，也就是能打开对话面板的时候。AI 没打开时，这一行和 Arc 一模一样。无痕窗口里不显示。
- 侧边栏隐藏时，按钮跟着看不到；鼠标移到左边缘、侧边栏滑出来时可以点。

**其他入口，都不占位置：**
- ⌥⌘A：改成和点这个按钮一样，开着就关，关着就开。
- 菜单栏的 View 菜单：在 Arc 的"Show/Hide Sidebar ⌘S"下面加一项"Show/Hide AI Conversations ⌥⌘A"。菜单里写着快捷键，用户看一次就能记住。
- 命令栏：输入"AI 对话"，打开面板并停在列表页。这个已经有。
- 把 tab 拖到窗口右边：面板关着时，从侧边栏拖 tab（一行、多选的几行，或 Favorites 的图标），指针拖到离窗口右边缘 40 点以内，右边出现一块和面板一样宽的放下区域：Space 主色的虚线框，中间写"松手交给 AI"。松手后的结果和对这些 tab 点右键选 Ask AI 一样：面板打开一个新对话，这些 tab 已经放在输入框里，等用户说话。指针还没到右边缘那 40 点时，拖到网页上照旧是分屏的落点；指针在放下区域里时，分屏落点不显示。面板开着时照旧拖到面板上。
- tab 右键菜单里的 Ask AI：已经有，照旧。
- 点通知、点列表顶上"别的 Space 在等你"的小条：已经有，照旧。
- 存下来的 AI 页面回到它的对话：AI 页面占一个 tab 时，卡片最上面加一行，和面板里页面上方那一行一样，左边是页面名和更新频率，右边是一个对话按钮。点了在右边面板打开做出这个页面的对话，对话在别的 Space 时先切过去。侧边栏里这一行的右键菜单也加一项"打开对话"。做出它的对话已经删掉时，这两处都不显示。

还想过一种做法，没有采用：鼠标移到窗口右边缘，面板就滑出来，就像 Arc 隐藏侧边栏后鼠标移到左边缘侧边栏会滑出来那样。没有采用是因为右边缘正是网页滚动条的位置，用户去拖滚动条时面板会自己弹出来。

## 不能坏的东西

- 面板现有的行为都保留：停止；授权的允许和拒绝；@ 列表；拖 tab 进来、多选、小标签上的 ×；加号菜单里换 agent 和模型、在文件夹里工作；页面存成 tab；页面里打勾和写笔记后的保存；横滑和底部小点；列表搜索；AI 给对话起名。
- 别的 Space 在等你的提示都保留：列表顶上的小条、Space 圆点外的一圈、数字、通知。
- 关掉面板、换 Space、退出再打开时，正在跑的回复照样在后台跑完，结果存进对话，列表里那一行显示它还在跑。
- agent 的"读对话"工具照样能列出、搜索、读到所有对话。
- 命令栏照样按全文搜到对话，点了在面板里打开，对话在别的 Space 时先切过去。
- AI 页面存成 tab、按时间自动更新、更新后侧边栏里的提示都照旧。
- 拖 tab 到网页上分屏、拖 tab 到 Space 圆点、指针在侧边栏上横滑换 Space、在网页上横滑前进后退都照旧。
- AI 没打开时，侧边栏和 Arc 一样。
- 无痕窗口里没有对话列表，也看不到别的窗口的对话。

## 验收

都用真实启动的 Brk，用真人的点击、按键和拖动去操作：
1. 发出第一句话后，侧边栏不多一行，对话出现在这个 Space 的列表里。
2. 用带对话行的旧数据启动：一行 pin 住的、一行在文件夹里的、一行在归档里的。启动后这些行都没有了，三段对话都在对应 Space 的列表里，AI 页面那一行还在。
3. 标题行的对话按钮：点一下开、再点一下关；有对话在等批准时显示数字；侧边栏拉窄时收进"…"菜单；AI 关着时没有这个按钮。
4. ⌥⌘A 开和关；View 菜单那一项；命令栏"AI 对话"。
5. 拖 tab 到窗口右边：出现放下区域，松手后打开新对话，tab 在输入框里；指针没到右边缘时，仍然是分屏的落点。
6. 鼠标停在列表一行上，左边对应的 tab 亮起来；停在小标签上，只亮那一个；文件夹收起时亮文件夹那一行。
7. 拖面板边缘把面板拉宽，重启以后宽度还在。
8. AI 页面 tab 上的对话按钮打开做出它的对话。
9. 把列表里的一行拖到别的 Space 圆点上，对话移过去，两个 Space 的列表都跟着变。
10. 用真实 Claude（Haiku 5.5）跑一遍完整的例子：拖两个 tab 进去问一句，让它做一个页面并存成 tab，鼠标停在列表那一行上看左边亮起的 tab，再从 AI 页面的对话按钮回到对话。原有的真实场景照样要过。

截图放在 `verify/ai-native/right-panel/`，浅色和深色 Space 各一套，每套五张：面板关着、按钮上有数字；悬停高亮；拖到右边的放下区域；拉宽的面板；AI 页面最上面那一行。另外照例跑完整的单元测试，并在同一块屏幕上和 main 对比截图：AI 没打开的场景应该和 main 一样。

## 实现时补的决定

做的时候有些地方上面的规则和设计稿没写到，下面是当时怎么定的，都可以改。

**更新后第一次启动。** 每段对话归到它那一行原来所在的 Space：在置顶、今天或其中的文件夹里，就是那个 Space；在归档里，就是归档前的 Space；在 Favorites 里或者根本没有行，就是它开始时的 Space；那个 Space 已经没有了，就是这个 profile 排在最前面的 Space。用户给那一行改过名字的，这个名字变成对话的名字，之后 AI 不再给它起名。归档里的整个文件夹或分屏不拆开改；以后从归档恢复出来，里面的对话行在恢复的那一刻拿掉。这一步每次启动都会跑一遍，但第二次起已经没有对话行，什么也不改。

**旧对话用过哪些 tab。** 以前没有记 tab 的 id，只能从对话记录里找回来：agent 回答里带的 `brk://tab/<id>` 链接，指向还在侧边栏里的 tab 的，算用过；Brk 写的"附上 A · B"那一行，按标题在这个对话的 Space 和 Favorites 里找同名的 tab。按标题找可能找错或找不到，这是能找回的最多的了。

**什么时候算"用过"。** 用户交进来的 tab，在消息发出去时记下，不是在拖进来时：拖进来又点 × 拿掉的不算。agent 那边，读过、打开过、切过去显示过的算；只是列出或搜到的不算。自动更新 AI 页面时读的不算，那是后台的事，不是这段对话做的。

**亮的样子。** 描边 1.5 点，颜色是这个 Space 的主色，和发送键同一个颜色；底色叠一层同样颜色的 12%。pinned 的 tab 关掉了页面但那一行还在时也亮，因为用户在侧边栏里看得到它、点得到它；置顶区整个收起来时置顶里的不亮。分屏里只用过一个 pane 也亮整个分屏那一行。侧边栏隐藏时什么都不亮，鼠标停着的那一行写"用了 N 个 tab，亮着 0 个"。

**按钮什么时候出现。** 条件是：普通窗口（不是无痕窗口，也不是 Little Arc），Max 开着，并且"命令栏提问"（Ask in Command Bar）这个开关开着，因为面板里的对话靠的就是它。这个开关关着时按 ⌥⌘A，弹出和命令栏提问关着时一样的提示。

**侧边栏拉窄时。** 分三档。侧边栏宽到 251 点以上，五个按钮都在：开关侧边栏、后退、前进、刷新、对话。窄一些时，刷新收进"…"，开关侧边栏还在，后退、前进、"…"、对话四个按钮换成 Arc 窄行用的 28 点小按钮；Arc 默认的 228 点宽就是这一档。再窄，照 Arc 自己的窄行，开关侧边栏和刷新收进"…"，对话按钮也收进去。收进去以后"…"菜单里那一项叫"AI 对话"，等你处理的数字用 macOS 菜单项自带的小数字显示，面板开着时这一项前面打勾。"…"菜单里只列收进去的那几项。

**View 菜单那一项。** 和 Arc 的"Hide Sidebar / Show Sidebar"一样，按现在的状态写"Show AI Conversations"或"Hide AI Conversations"。窗口不能打开面板时这一项藏起来，⌥⌘A 照样有效，这样 AI 没打开时 View 菜单和 Arc 一模一样。命令栏里"AI Conversations"那一行没有跟着变成开关，还是打开面板并停在列表页。

**再打开时停在哪。** 面板关掉时（点标题行的按钮、按 ⌥⌘A、点面板上的 ×），记下这个 Space 的面板停在哪一页、显示的是哪段对话。再打开时回到那里；那段对话已经删掉或移到别的 Space，就停在列表页。

**拖宽。** 宽度按窗口记，和侧边栏宽度一样存进 state.json；⌘N 开的新窗口用原窗口的宽度。记下的宽度可以比窗口一半还宽，窗口变窄时显示的宽度照样不超过窗口的一半、也不挤得网页卡片少于 400 点，窗口再变宽时回到记下的宽度。双击那条空隙回到默认的 360 点。告诉 agent 的页面宽度，按这个窗口现在实际显示的面板宽度算。

**拖到窗口右边。** 放下区域和面板将要打开的宽度一样，上下到网页卡片的上下边，盖在网页卡片的右边。指针进到最右边 40 点时出现，之后只要指针还在这个区域里就一直在。拖的是文件夹时，交进去的是文件夹，和在文件夹上点 Ask AI 一样。从侧边栏底部拖 Space 圆点到右边缘不算，只有 tab、多选的几行、Favorites 的图标和文件夹。

**把列表里的一行拖到 Space 圆点上。** 拖的时候那一行跟着指针走，指针下的圆点显示和拖 tab 过去时一样的放下效果。只能移到同一个 profile 的 Space，因为 agent 只能看那个 profile 的 tab；拖到别的 profile 的圆点上什么也不做。面板正显示这段对话、而它被移走了的，面板把它收起来，回到列表页。

**删掉 Space。** 确认框里多的那一句跟着列表文字的语言。这个 profile 没有别的 Space 时，对话留在原地不动，只在 Library 的"AI 对话"页里看得到，确认框也不多写这一句。删掉以后按 ⌘Z 恢复 Space，对话也移回去。

**AI 页面最上面那一行。** 画在网页卡片的颜色上（白或深灰），样子照面板里页面上方那一行：左边页面名和"· 每小时"这样的更新频率，下面一条细线，右边是对话气泡按钮，鼠标停上去写"打开对话"。侧边栏那一行的右键菜单里，"打开对话"排在 Brk 自己的页面菜单项的第一个，在"Refresh"前面。文字跟着做出这个页面的对话的语言。页面上原来的"在 tab 里打开"（打开存下来的页面）不是对话的，留着。

**图标。** 面板标题栏的列表图标从三条横线换成了对话气泡，和标题行的按钮、命令栏那一行是同一个图标，照规则"同一个"。

**直接输入对话地址。** 在命令栏输入 `brk://conversation/<id>`，在面板里打开这段对话，不开 tab。不管从哪里冒出一行对话 tab（恢复旧的归档、撤销），都在那一刻拿掉，打开着它的窗口改在面板里显示这段对话。

**归档里的"删除对话"。** 对话不再进归档，归档右键菜单里的"Delete Conversation…"随之去掉，"Delete Page…"留着。彻底删除对话在面板列表的右键菜单和 Library 的"AI 对话"页里。
