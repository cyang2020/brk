# AI 对话面板的样子

## 背景

2026-11-09，用户看了现在的对话面板，说"我觉得这个panel本身就很丑 下面的对话框更恶心"。当时面板里是"盯着这三个商品页的价格，每小时更新一次"那次对话。用户后来定了方向："我觉得要融入窗口的 尤其是和spaces的theme要对齐"。

截图里能看到这些问题：
- 面板是一张浮在网页上面的灰色卡片，有自己的边框和系统毛玻璃底色，跟窗口里其他地方的 Space 颜色无关，换 Space 或换主题也不会变。
- 标题"Max · Claude · Haiku 5.5"写的是用了哪个模型，看不出这次对话在做什么。标题下面又用大字把用户的第一句话重复了一遍。
- 右上角是两个写字的系统按钮，"Open as Tab"和"Close"。
- agent 每用一次工具就单占一行，写的是英文工具名，比如"✓ Keep a page as a tab"。
- 自动更新的提示是一行英文："Refreshed "商品价格监控": new data."
- 底部挤了一行"Tab tools on · others ask"和"Work in a Folder…""Agent…"两个按钮，下面是系统默认的单行输入框，旁边一个写着"Send"的按钮。
- 回答里画出的页面在窄面板里被截掉了右边，"11-0""11:3"都只露出一半。

## 改法

窗口里其他地方，包括左边的侧边栏、地址栏和 tab 行，颜色都取自当前 Space 的主题。面板显得突兀，是因为它用的是 macOS 默认的控件和颜色。所以面板不再自己定颜色，里面每样东西都改用侧边栏里已有的一种样子。

具体是三条：
1. 面板不再浮在网页上。打开面板时，网页卡片的右边往左让出位置，面板成为窗口右边的一栏。它和侧边栏一样直接画在 Space 底色上，渐变和颗粒都一样，没有自己的边框、阴影和底色。面板和网页卡片之间的空隙，与侧边栏和网页卡片之间的空隙相同。
2. 面板里的每个部分都对应侧边栏里的一样现成东西，对应关系见下表。
3. 所有颜色都从 Space 主题里取，所以新建 Space、换颜色、换深浅时，面板会自动跟着变，不用给每种主题单独调。

设计稿在 `docs/design/ai-panel-mockup.html`，用浏览器打开就能看。上半部分是浅米色 Space 里的整个窗口：左边是侧边栏，中间是网页卡片，右边是面板。下半部分把同一个面板放进浅蓝、渐变紫、深色三种 Space。稿子里的颜色是照 Brk 的主题规则估出来的，实现时用 Space 的实际取值，不照抄稿子里的数。

| 面板里的部分 | 照着侧边栏里的哪样东西 | 浅色主题 / 深色主题 |
|---|---|---|
| 面板底色 | 侧边栏底色 | 不画，直接露出窗口的 Space 底色 |
| 回答正文 | 侧边栏 tab 标题的字色 | 用 `sidebarInk`（Space 主色调到很深）/ 白色 0.9 |
| 次要的灰字：时间、步骤行、"每小时"这类说明 | "Today"这类分组标题 | `foregroundStrong` 黑 0.45 / 白 0.45 |
| 用户说的话 | 当前选中的 tab 那一行 | `tabCurrent` 白 0.85 加 `tabShadow` / #FAFBFF 0.2，深色下没有阴影 |
| 底部输入框 | 同上 | 同上，圆角 12 |
| 工具步骤那一行、更新提示小条、拖进来的 tab 小标签、@ 列表里没选中的行 | 地址栏那一条的淡色底 | `itemBackground` 0.05 / 0.1，鼠标移上去用 `itemHover` |
| 分隔线、回答里表格的线 | 侧边栏分隔线 | `separator` |
| 回答里画出的页面 | 网页卡片 | 白色 / 深灰，和网页卡片同样的圆角和阴影 |
| 发送键、链接、侧边栏上表示有新数据的小圆点 | 这个 Space 的主色 | 用 `themeShade` 把主色调到能放白字的深浅；深色主题下调亮，按键上的箭头用深色 |

## 各部分

**标题栏。** 左边是这次对话的名字，也就是对话 tab 的名字。AI 给对话起好名字之前，先用用户第一句话的开头。右边是三个小图标：新对话、在 tab 里打开、关闭，鼠标停在上面时显示文字说明。agent 正在做事时，标题旁边有一个小的转圈。模型名不放在标题里，放进加号菜单。用户第一句话不再在标题下面用大字重复，它就是对话里的第一条消息。

**对话内容。** 用户说的话靠右，用"当前选中 tab"的样子。agent 的回答不加底色，直接写在 Space 底色上。agent 连着用的几次工具折成一行，用大白话总结做了什么，比如"✓ 读了 3 个 tab，做了一个页面 ›"，点一下展开每一步。自动更新、出错这类系统消息是居中的一个小条，比如"11:32 已更新 · 水壶降了 €4.50"。

**回答里的页面。** 页面在面板里显示成一张卡片。卡片上方一行写页面名和更新频率，比如"商品价格监控 · 每小时"，右边一个"在 tab 里打开"的图标。页面按面板宽度排版，不能截掉右边；Brk 给 agent 的页面样式要能在面板这么窄时换行。那套样式里的颜色，比如图表里标出最便宜的那一条，也用这个 Space 的主色。

**授权框。** 先用一句话说清 agent 想做什么，比如"Claude 想在 ~/Desktop 里运行一条命令"。命令本身默认收起，点"查看命令"才展开。"允许"用 Space 主色，"拒绝"用 `itemBackground`。整块底色用 `itemBackground`，不再用系统强调色。

**输入框。** 一整块，用"当前选中 tab"的样子，圆角 12：
- 拖进来或 @ 进来的 tab 小标签放在框里的上方，每个带 ×。
- 左边是加号，点开是一个菜单：在文件夹里工作…、换 agent 和模型（显示现在用的，比如"Claude · Haiku 5.5"）、权限（现在是"tab 工具直接用，其他都先问"）、agent 设置…。原来底部那一行文字和两个按钮都收进这个菜单。
- 提示文字是"继续问，或输入 @ 添加 tab"。
- 右边是圆形发送键，用 Space 主色。agent 在做事时它变成停止键。
- 框可以写多行，最多长到 6 行左右。回车发送，Shift 加回车换行。
- @ 列表从框的上方弹出，样式和框一致。
- 把 tab 拖到面板上时，框外显示一圈 Space 主色的线，表示松手就能放进来。

**文字的语言。** Arc 没有的、Brk 自己的 AI 界面文字，跟着系统语言用中文或英文，包括标题栏说明、步骤总结、系统消息、授权框、加号菜单和提示文字。照 Arc 做的界面保持原样。

**对话单独占一个 tab 时。** 规则相同，只是底色换成网页卡片的白色或深灰。内容放在中间一栏，宽度不超过 720 点。用户的话和小条在白色上改用 `itemBackground`；输入框改用卡片色，加一条 `separator` 颜色的细边和 `tabShadow`。

## 不能坏的东西

外观改了，现有行为一样都不能少：
- 停止。
- 授权的允许和拒绝。
- @ 列表的上下键、回车和 Esc。
- 拖 tab 进来、多选、小标签上的 ×。
- 在 tab 里打开、关闭、取消。
- 页面的"存成 tab"和右键菜单。
- 页面里打勾和写笔记后的保存，包括面板隐藏、切走、关窗、退出时先保存。
- 在文件夹里工作。
- 去 Max 设置页的入口。

真实场景测试用的控件名（`ai-*`）可以改，但相应的场景要同时改好，并且仍然用真人的点击和按键去操作。

## 验收

在四种 Space 里用真实启动的 Brk 各截一张图：默认浅色、浅蓝、渐变紫、深色。四张图都用设计稿里的"盯着这三个商品页的价格，每小时更新一次"那次对话，放在 `verify/ai-native/panel-ux/` 里，和设计稿并排比较。比较时看这几点：
- 面板底色和侧边栏连成一片；
- 用户的话和输入框跟侧边栏选中行是同一种样子；
- 发送键是这个 Space 的颜色；
- 回答里的页面没有被截掉。

另外照例跑完整的单元测试、AI 相关的真实场景，以及和 main 在同一块屏幕上的截图对比。
