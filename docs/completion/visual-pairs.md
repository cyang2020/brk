# Arc 与 Brk 画面对照清单

本文列出要在真实 Arc 和 Brk 上各截哪些图，以及怎么截、怎么存、怎么比。对照的目标是 `docs/completion/features.json` 里声明了"画面检查"的 58 行功能，外加一组清单没有要求但用户看得见的界面。截图由人在自己的 Mac 上完成；每一对图比完后记录"一致 / 有意不同 / 要修"，"要修"的项再分组并行修。

## 背景

清单里 58 行功能带"画面检查"要求。到 2026-11-02 为止，这 58 行里没有一行拿真实 Arc 的画面比过：已有的"画面通过"记录全部是只看 Brk 自己的截图确认排版可读。反编译出来的 Arc 1.170 布局常量（`docs/arc-anatomy/layout-constants.md`）给了尺寸参考，但不能代替实际画面。所以这一轮的目的就是补上真实参照。

58 行按状态分：17 行已验证、29 行已实现、7 行半成品、3 行没做、2 行卡住。没做和卡住的几行（App 图标面板、Dock 图标、菜单栏图标、扩展弹窗）也要先拍 Arc 这边，给后面实现的人当参照。

## 方法

### 两边保持一致的条件

1. **同一台 Mac、同一块屏幕**，缩放保持 2x（Retina）。两边的图都不要缩放。
2. **窗口尺寸 1280 × 776 点**。这是 Arc 新窗口的默认大小。Arc 和 Brk 都用下面这行设成一样（把 `Arc` 换成 `Brk` 再跑一次）：
   ```sh
   osascript -e 'tell application "System Events" to tell process "Arc" to set size of front window to {1280, 776}'
   ```
3. **侧栏宽度 228 点**。两边都双击侧栏右边缘，宽度会复位到 228。
4. **工具栏默认隐藏**（Arc 默认就是隐藏；Shift+Cmd+D 切换）。只有专门写了"工具栏显示"的那张图才打开。
5. **系统外观用浅色**。只有写了"深色"的那几张图才切到系统深色。
6. **同一个 Space 主题**。两边各建一个叫"对照"的 Space，主题选预设第一页的第一个色块，强度和噪点都保持默认，不加纹理。
7. **同样的页面内容**。本仓库 `scripts/station/fixture-site/` 下有 9 个不含任何个人数据的测试页。先在终端启动一个本地站点，两边都打开同样的地址：
   ```sh
   python3 -m http.server 8764 --directory scripts/station/fixture-site
   ```
   地址是 `http://127.0.0.1:8764/home.html` 等。页面标题分别是 Home、Docs、Design notes、Inbox、Interaction states、Interface comparison、Long title for truncation and readable sidebar ellipsis、Secondary reference、Visual fixture。
8. **同样的侧栏内容**。两边都摆成：
   - 收藏（4 个，顺序一致）：wikipedia.org、developer.mozilla.org、github.com、apple.com。
   - 置顶区：Home、Docs、一个叫"资料"的文件夹，里面放 Design notes 和 Interface comparison。
   - Today 区：Inbox、Long title…、Secondary reference、Visual fixture，当前选中 Visual fixture。
9. 鼠标移出窗口再拍，除非那张图就是要拍悬停或拖动。
10. 不用你自己日常用的 Arc Space 和账号内容拍图。要登录账号的只有收藏角标那一组，而且只拍角标那一小块。

### 怎么截

- **整窗**：Cmd+Shift+4，按空格，按住 Option 点那个窗口（按 Option 是去掉窗口阴影）。得到的 PNG 就是那个窗口本身，2x 像素。
- **菜单、弹层、提示条这类另开窗口的东西**：Cmd+Shift+4 直接拖一个框，把主窗口和弹出的东西一起框进去。
- **要按着键、悬着鼠标、或者只闪现几秒的状态**（切换器、悬停卡、加载光晕、提示条、拖动预览）：Cmd+Shift+5，选项里把计时器设成 5 秒，选"捕捉所选窗口"或"所选部分"，点开始后在 5 秒内把状态摆出来并保持住，等它自动拍。
- **动画**（Space 划动、Peek 打开、分屏拖入）：Cmd+Shift+5 录屏 3 到 5 秒，两边各一段。
- 想要不动手就把 Arc 窗口拍下来（例如拍"窗口非激活"状态），用仓库里的 `scripts/capture-arc-reference.swift`，它只读窗口像素，不会碰 Arc。用法见 `docs/arc-anatomy/offline-reference-lab/CAPTURE.md`。

### 怎么存

目录 `2a96a9d7f0:verify/visual-pairs/<编号>/`，文件名 `<编号>-<状态字母>-arc.png` 和 `<编号>-<状态字母>-brk.png`，例如 `P02/P02-b-arc.png` 与 `P02/P02-b-brk.png`。录屏同名改成 `.mov`。拍完一组在 `9c78e46476:verify/visual-pairs/results.tsv` 里记一行：编号、状态字母、结论（一致 / 有意不同 / 要修）、差异描述、处理。

### 怎么比

两张图在"预览"里各开一个窗口，都放到 100%，并排看。按这个顺序过一遍：

1. 位置和尺寸：元素在哪、多大、离边多远。
2. 间距和对齐：行高、行间距、左右缩进、文字和图标是否对齐。
3. 字体：字号、粗细、颜色、截断方式（省略号在哪）。
4. 颜色：背景、文字、选中态、悬停态、分隔线。
5. 形状：圆角、边框、阴影、半透明。
6. 图标：大小、风格、位置。
7. 文案：措辞、大小写、标点。
8. 状态：选中、悬停、禁用、加载中各自长什么样。
9. 裁切：有没有被挡住、溢出、换行异常。

"有意不同"只用于我们明确决定过不照抄的地方（例如 Brk 的 AI 用本机命令行工具而不是 ChatGPT 账号，设置页里多出的安装/选择控件就是有意不同）。拿不准的一律记"要修"，由我来判断。

### 先拍什么

先拍 P01 到 P07 和 P12、P20 到 P23、P29：窗口外壳、侧栏、菜单、几种窗口类型、主题明暗。这些影响所有其他画面，先把它们对齐，后面的差异才不会被外壳差异淹没。其余按顺序。
