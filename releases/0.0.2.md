# Brk 0.0.2

## Tabs and resource use

- Moving an open tab between windows keeps the same webpage, including its current content and form state.
- Idle background tabs can freeze and be reclaimed when memory is needed. Returning to a reclaimed tab reloads it; Chromium protects pages with unsaved form input.
- Window changes preserve queued navigation, page history and temporary website permissions. Temporary permissions expire when you leave the document.

## Extensions

- Add Extension now opens Chrome Web Store. Installed extensions appear automatically in site controls.
- Extension installation confirmations display their full title and attach to the browser window that opened them.
