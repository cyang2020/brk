# Brk 0.0.52

- Fixed Brk quitting when a website opened one of Chromium's own dialogs: a passkey or security key sign-in, a site asking for a username and password before it loads, print preview from a page's Print button, and "Sign in with Google" and other sign-in prompts (FedCM). These dialogs now open over the page they belong to, and follow the tab if it moves to another window. Opening ChatGPT no longer makes Brk quit.
- Fixed Brk quitting when a page crashed in a window with more than one tab. The page now shows "This tab has crashed" with a Reload button, as it already did in other cases.
- If Brk quits unexpectedly, the next launch no longer reloads the pages that were on screen by itself. Their tabs stay where they were and show a Reload button, so a page that makes Brk quit can't make it quit again on every launch.
