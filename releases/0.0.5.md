# Brk 0.0.5

- Fixed an intermittent quit hang when background workers were starved under heavy CPU load.
- Hover over the update notice to open a card with automatic updates, version-specific release notes, and a gently animated Restart and Update button.
- Automatic updates wait until the screen is locked, asleep, or showing a screensaver. Playing media, active downloads, and open dialogs postpone a restart.
- After an update, a heart animation and See What’s New introduce the installed version. Read or dismiss the summary once; it stays dismissed across windows and restarts.
- Update animations respect Reduce Motion. Release notes remain available from the Help menu.
- Improved desktop password-manager integration and fixed the Tidy group rename field.
