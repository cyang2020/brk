# Brk 0.0.1

## Updates and release history

- Brk can download a signed update from the sidebar, then restart into the new version. You can also choose Brk > Check for Updates….
- Help > Release Notes now keeps a versioned history of useful changes. Each GitHub release keeps its own notes and downloads.
- If you use an older 0.1.0 copy, install this release from the disk image once. Those copies have no in-app updater. The new 0.0.1 label starts the versioned release history; increasing build numbers keep future updates in order.

## Downloads and appearance

- Active download cards keep their filled background and show a pale progress disc, including in dark themes.
- Websites respect their own dark color scheme without forced color inversion or an injected canvas background.
- The theme color picker now converts Display P3 correctly, keeping its saved and displayed colors consistent. You can drag the noise control from its center, undo changes, and adjust it with accessibility controls.
- Imported Space colors, gradient direction, theme transparency, and sidebar animations more closely follow Arc.

## Browser and installation fixes

- BrkCore embeds pages directly in Brk windows, removing the extra Chromium page-host windows that could remain behind them.
- Quitting no longer waits on background system media-permission checks.
- Disk-image packaging preserves the signed app and verifies its signature inside the finished image, fixing downloaded apps that failed strict verification.
- Site controls close when you click outside. Command-W closes the controls without closing the tab behind them.
